# Aldren Veyr — Ficha de Herói

Projeto desenvolvido em HTML, CSS e JavaScript.

## Arquivos
- `index.html`: Sobre o Herói.
- `atributos.html`: Atributos, habilidades e experiência.
- `arsenal.html`: Inventário e conquistas.
- `contato.html`: Contato com a Guilda.
- `style.css`: estilos e responsividade.
- `script.js`: interações do projeto.
- `imagens/`: imagens utilizadas nas páginas.

## Interações implementadas
- Menu responsivo na página inicial.
- Saudação conforme o horário, caso exista um elemento com `id="saudacao"`.
- Modo da Guilda, caso exista um botão com `id="botaoModo"`.
- Botão para revelar e ocultar a história do herói.
- Inventário gerado a partir de um array de objetos e filtros por categoria.
- Contador de itens exibidos.
- Barra de experiência com progresso salvo no navegador.
- Validação de nome, e-mail e mensagem no formulário.

## Como executar
Abra `index.html` no navegador. Para editar o projeto, mantenha os arquivos HTML, `style.css`, `script.js` e a pasta `imagens` juntos, como estão organizados.

## Observação
O formulário apresenta uma confirmação visual no próprio navegador; ele não envia dados para um servidor ou e-mail.
